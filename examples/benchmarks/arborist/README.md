# Arborist paper example

`list_fold.ae` translates Example 3.1 of *Efficient Bottom-Up Synthesis for Programs
with Local Variables* (POPL 2024). It preserves the single `[1, 2, 4] → 7` example,
which permits multiple callback implementations.

The [backend documentation and comparison runner](../../synthesis/arborist/README.md)
remain with the local demos. The extra examples in `list_sum.ae` were constructed
for Aeon and are not part of the paper specification.
