# BLAZE / SYNGAR benchmarks

Programs associated with *Program Synthesis using Abstraction Refinement* (POPL 2018).

- [strings/](strings/): 109 SyGuS PBE string-transformation ports; regenerate with `scripts/sygus_to_aeon.py`.
- [matrix/](matrix/README.md): ten tasks reconstructed from the paper's matrix DSL and running example.
  These are not the unavailable original 39-task matrix dataset.

Local AFTA backend demos remain in [examples/synthesis/afta/](../../synthesis/afta/).
