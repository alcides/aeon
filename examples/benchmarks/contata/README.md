# Contata benchmarks

Ports of *Relational Synthesis of Recursive Programs via Constraint Annotated
Tree Automata* (CAV 2024).

- [reference/](reference/): 30 artifact transcriptions, with reference bodies and specifications.
- [synth/](synth/): nine hole-bearing variants supported by the current CATA/Contata domains.

The small [backend smoke examples](../../synthesis/cata/README.md) remain separate.
The subdirectory READMEs describe representation choices and current synthesis limits.
