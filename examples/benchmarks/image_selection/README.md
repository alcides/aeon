# Image selection predicates

Six Aeon adaptations of scenarios from or inspired by *Synthesizing Optimal Object
Selection Predicates for Image Editing using Lattices* (arXiv:2504.03155).
The source headers distinguish motivating examples from inspired scenarios.

These use categorical/numeric object records and locally encoded labels rather
than the original image-processing pipeline or a checksum-pinned artifact dataset.
They should not be reported as a reproduction of the paper's experimental corpus.
